A percentage increase calculator shows how much a number has grown, expressed as a percentage of where it started. Enter an old value and a new value, and this percent increase calculator returns the percentage change, the difference, and the working. It can also add a percent to a number, find the original value before an increase, work out a yearly growth rate, and compare one percentage with another. It suits anyone checking a salary rise, a price hike, a rent increase, an investment return, or a school problem. Use the calculator above, then read on to see how each result is calculated and which mistakes to avoid.

Quick answer:

Percentage increase = (new value − old value) ÷ old value × 100. For a rise from 80 to 100, that is (100 − 80) ÷ 80 × 100 = 25%.

1. How the Percentage Increase Calculator Works

This percent increase calculator has five modes, each answering a different question. Find % increase compares an old and a new value and reports the percentage change. Add % to a number applies a known percentage to a starting value, either as an increase or a decrease. Find original value works backwards from a final value and a percentage. Yearly growth turns a start value, an end value, and a number of years into a steady annual rate. Percent to percent compares two percentages, such as an interest rate that moves from 4% to 5%.

Every mode shows the main answer, supporting figures such as the difference and the multiplier, and the calculation written out step by step, so you can follow the arithmetic or copy it into your own work. Use it to compute percentage increase in seconds, or as a percentage growth calculator when you want growth as a percentage per year.

Assumptions:

Percentage change is measured against the starting value, so a starting value of 0 cannot be used. A negative starting value is handled by dividing by its absolute value. A decrease cannot be larger than 100% when you apply it to a number, because that would take the value below zero. The yearly rate assumes steady compound growth and needs positive start and end values. Rounding changes only what you see, never the calculation.

3. Percentage Increase Formula

Percentage increase = (final − initial) ÷ |initial| × 100

This is the percentage increase equation. The final value is the new number, the initial value is the old one, and the bars mean the starting value is used without its sign.

How to calculate percentage increase

  1. Subtract the old value from the new value to get the increase.
  2. Divide the increase by the old value.
  3. Multiply the result by 100 to get the percentage.

The same three steps let you calculate an increase as a percentage for any pair of numbers, whether they are prices, pay, scores, or counts. The result is the rate of increase relative to where you started.

Where:

  • Final value = the new number after the change.
  • Initial value = the old or starting number, which is the base of the percentage.
  • 100 = the factor that turns a decimal into a percentage.

The other modes use closely related formulas:

New value = original × (1 + percentage ÷ 100) Original value = final ÷ (1 + percentage ÷ 100) Yearly rate = (final ÷ initial)^(1 ÷ years) − 1 Percentage-point change = new % − old %

For a decrease, replace the plus sign with a minus sign. The part in brackets is the multiplier: a 12.5% increase multiplies the value by 1.125, and a 20% decrease multiplies it by 0.8. A result below zero in the first formula simply means the value fell, so the same formula also gives a percentage decrease.

4. Worked Examples

Example 1: Salary raise

A salary rises from 50,000 to 53,500. These are the calculator's default values.

StepWork
InputsInitial value = 50,000 and final value = 53,500
Formula(final − initial) ÷ initial × 100
Calculation(53,500 − 50,000) ÷ 50,000 × 100 = 3,500 ÷ 50,000 × 100 = 0.07 × 100
ResultA 7% increase (multiplier 1.07)

Example 2: Price increase

A product costs 80 and the price goes up by 12.5%. The amount added is 80 × 0.125 = 10, so the new price is 90. The same answer comes from multiplying: 80 × 1.125 = 90.

Example 3: Finding the original value

A bill is now 1,260 after a 5% increase. The multiplier is 1.05, so the original was 1,260 ÷ 1.05 = 1,200. A common error is to subtract 5% from 1,260, which gives 1,197 and is wrong, because the 5% was taken from the original amount, not from the new one.

Example 4: Yearly growth

An investment grows from 10,000 to 16,105.10 in 5 years. The total change is 61.051%. The steady annual percentage increase, or yearly rate, is (16,105.10 ÷ 10,000)^(1/5) − 1 = 10%. The simple average, 61.051% ÷ 5, is about 12.21%. These two numbers differ because compounding means each year's growth builds on the last, so the compound rate is the better description of steady growth.

5. Percentage Increase of a Percentage

Percentages of percentages are a frequent source of confusion, because there are two valid ways to describe the same move. Take a rate that goes from 20% to 25%.

  • Percentage points: 25 − 20 = 5 percentage points. This is the plain gap between the two figures.
  • Relative increase: 5 ÷ 20 × 100 = 25%. This says the new rate is a quarter bigger than the old one.

Both statements are true, so say which one you mean. Headlines often use the relative figure because it sounds larger, while the points figure is easier to picture. The Percent to percent mode shows both side by side. A different question is increasing a percentage by a percentage. Raising 20% by 10% means 20 × 1.10 = 22%, not 30%, and you can check it with the Add % to a number mode.

6. Understanding Your Result

The result is exact for the numbers you entered, and it is rounded only for display. A rise of 7% on a salary is a precise figure, while a rate worked out from rounded inputs is only as accurate as those inputs. Use the result to make a practical decision, such as whether a pay offer beats inflation or whether a price rise is bigger than last year's. The sign tells you the direction: positive for an increase and negative for a decrease. The multiplier is the same result in another form, since a 7% increase equals a multiplier of 1.07 and a 100% increase equals a multiplier of 2, which means the value doubled. Percentage increases can exceed 100%, but a decrease cannot go beyond 100% for ordinary quantities.

Increases and decreases are not mirror images. If a value rises 50% from 100 to 150, a 50% decrease then lands on 75, not 100, because the second percentage is taken from a larger base. To get back from 150 to 100 you need a decrease of about 33.33%. The Find % increase mode shows this as the change needed to return to the starting value, which is useful when judging whether a rise has really been recovered.

7. Money, Units and Rounding

The calculator works with any kind of number, such as money, weight, distance, or sales. Use the currency box only to add a symbol to the display. It does not convert currencies, so compare values in the same currency and the same unit. If your old value is in one unit and your new value in another, convert one of them first.

Percentages are usually reported to one or two decimal places, so the default rounding is two decimals. Choose four or six decimals when the result feeds into another calculation, and round only at the end. A tiny change on a large number can show as 0.00%, which is why extra decimals sometimes help.

8. Practical Tips

  • Always put the older value first. Swapping old and new turns an increase into a decrease with a different percentage.
  • Write down what the percentage is measured against, such as last year's salary or the original price.
  • For repeated yearly changes, use the Yearly growth mode instead of adding the percentages together.
  • Check a result by working forward: multiply the old value by the multiplier and confirm you reach the new value.
  • When comparing two rates, state whether you mean percentage points or a relative change.

9. Common Mistakes

  • Dividing by the new value. The base is the old value. Using the new one understates an increase.
  • Forgetting to multiply by 100. A result of 0.07 is the decimal form of 7%.
  • Adding yearly percentages. Three years of 10% growth is 33.1% in total, not 30%, because the growth compounds.
  • Reversing an increase by subtracting the same percentage. Undoing a 25% rise needs a 20% fall, not 25%.
  • Mixing up percentage points and percent. A move from 4% to 5% is 1 point and a 25% relative rise.

10. Related Calculations and Use Cases

Percentage change appears in almost every area of everyday life. Employees compare pay rises and landlords set rent increases. Shop owners track price changes, and investors measure returns over time. Teachers compare test scores between terms, and analysts look at month-on-month sales growth. The same formula covers all of them, with the only difference being what the starting value represents.
